# Syst PE prototype

This directory currently contains the `syst` 2×2 matrix-multiply prototype,
not the complete future Axon processing element.

The RTL and `axon:pe:syst:0.1.0` core pass strict Verilator lint. Functional
simulation and integration verification are not yet part of this maturity
claim. See `doc/syst.md` for the implemented microarchitecture and known
limitations.
